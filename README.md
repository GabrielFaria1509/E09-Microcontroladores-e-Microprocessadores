# E09 - Microcontroladores e Microprocessadores 🚀

Este repositório contém os códigos em C e exercícios desenvolvidos para a disciplina **E09 - Microcontroladores e Microprocessadores**, do curso de Engenharia de Software no Instituto Nacional de Telecomunicações (Inatel).

## 💻 Tecnologias e Ferramentas
* **Linguagem principal:** C
* **Microcontroladores/Placas:** [Arduino]
* **Ambientes de Desenvolvimento (IDEs):** 
  * [OneCompiler](https://onecompiler.com/c) (utilizado atualmente para testes e compilações rápidas)
  * Arduino IDE (para implementações futuras no hardware)

## 📂 Estrutura do Repositório

* 📁 `Exercicios/`: Contém todos os códigos, lógicas e resoluções dos exercícios propostos durante as aulas.

## ⚙️ Como Executar os Códigos

**Para testar rapidamente (via OneCompiler):**
1. Acesse o site do [OneCompiler para C](https://onecompiler.com/c).
2. Copie o conteúdo do arquivo `.c` desejado da pasta `Exercicios/`.
3. Cole no editor do navegador e clique no botão **Run** para ver a saída no terminal.

**Para gravar no hardware (Futuro, via Arduino IDE):**
1. Clone este repositório para a sua máquina:
   ```bash
   git clone [https://github.com/SEU_USUARIO/E09-Microcontroladores-e-Microprocessadores.git](https://github.com/SEU_USUARIO/E09-Microcontroladores-e-Microprocessadores.git)
